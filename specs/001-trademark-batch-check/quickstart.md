# Quickstart: 候補名の一括チェックと商標照合

**Feature**: `001-trademark-batch-check`

## 1. 準備

```bash
docker compose -f compose.dev.yaml up -d
pnpm install
pnpm db:migrate
DATABASE_URL=postgres://app:app@localhost:55433/app pnpm --filter @app/importer seed-fixture
pnpm dev   # web と worker
```

## 2. 自動テスト

```bash
pnpm lint && pnpm typecheck
pnpm test        # 単体（正規化、読み、類似の度合い、利用回数）と結合（照合、実行、やり直し、期限、認可）
pnpm test:e2e    # 一括チェックの実行と比較表、区分の絞り込み、上限
```

期待結果: すべて通る。検証用データの組で、同一の判定が 100%（SC-003）、類似の 90% 以上が上位 20 件に入る（SC-004）。

## 3. 手で確かめるシナリオ

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | `/checks/new` で `サクラノミチ`、`さくらのみち`、`ソラマメ / ソラマメ` を入れて実行 | 重複の 1 件がまとめられ、2 件の比較表になる。「確認中」から結果に変わる |
| 2 | 検証用データにある商標と同じ文字の候補を実行 | 「同一の商標あり」と番号・権利者・区分・状態、公式サービスへのリンク |
| 3 | 区分に第 9 類だけを選んで実行 | 第 9 類を含む商標だけが該当になる。比較表に「第 9 類」 |
| 4 | 実行直後にタブを閉じ、トップを開き直す | 直近のチェックに表示があり、開くと結果がそろっている |
| 5 | worker を止めて実行し、2 分待つ | 候補が「不明」になり、残りの件数が戻る。worker を起動してやり直すと結果が出る |
| 6 | 今月の使用を 48 件にして 3 件を実行 | 実行できず、残り 2 件と戻る日時が示される |
| 7 | 別の利用者でログインし、1 のチェックの URL を開く | 404 |

## 4. ログの確認

worker と web のログに、候補名と読みが出ていないことを確かめる（`candidateId` と件数だけ）。

- 特許庁の一括ダウンロードの申込が通り、`JpoBulkMapping` を実装して実データを取り込めた（`docs/architecture.md` §9 R1）。
- 実データで、J-PlatPat の固定アドレスのリンクが開ける（research R8）。
- 実データの件数で、類似の検索が p95 30 秒以内に終わる（SC-002）。
