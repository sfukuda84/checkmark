# 契約: 画面（ルート）

**Feature**: `000-app-basic`

`apps/web` が提供する画面。「要ログイン」の画面は `requireUser()` を通す。`requireUser()` は、未ログインなら `/sign-in` へ、未確認なら `/verify-email` へ、停止中なら `/suspended` へ、規約に未同意なら `/consent` へ移す。

| パス | 対象 | 内容 | 要件 |
|---|---|---|---|
| `/sign-up` | 未ログイン | メールアドレス、パスワード、規約とプライバシーポリシーへの同意のチェック、Google で登録するボタン | FR-001、FR-002、FR-005、FR-017 |
| `/sign-in` | 未ログイン | メールアドレスとパスワード、Google でログインするボタン、パスワードを忘れた場合のリンク | FR-006、FR-007 |
| `/verify-email` | 未確認のログイン中、または登録直後 | 確認メールを送ったことの案内、送り直しのボタン | FR-003、FR-004 |
| `/verify-email/callback` | 誰でも | 確認リンクの戻り先。成功したら `/` へ、失敗（期限切れなど）したら理由と送り直しを示す | FR-003 |
| `/forgot-password` | 未ログイン | メールアドレスの入力。登録の有無によらず同じ案内を出す | FR-009 |
| `/reset-password?token=` | 誰でも | 新しいパスワードの入力。トークンが無効なら理由と再依頼への導線を示す | FR-010、FR-011 |
| `/consent` | ログイン中 | 未同意の文書（現行の版）の表示と同意ボタン、ログアウト | FR-019、FR-020 |
| `/account` | 要ログイン | メールアドレスの表示と変更（パスワードを持つ場合だけ）、退会。Google だけのアカウントには、変更できない理由を示す | FR-012、FR-012a、FR-015 |
| `/account/reauth` | 要ログイン | パスワードの再入力、または Google でのログインし直し。終わったら元の操作へ戻る | Clarifications Round 1 |
| `/account-deleted` | 誰でも | 退会が完了したことの案内 | FR-016 |
| `/suspended` | 誰でも | 利用が停止されていることと問い合わせ先 | FR-026 |
| `/maintenance` | 誰でも | メンテナンス中の表示（HTTP 503） | FR-028 |
| `/legal/terms`、`/legal/privacy` | 誰でも | 現行の版の本文 | FR-018 |
| `/` | 要ログイン | ログイン後の最初の画面（000 では空の案内。`001` でチェックの画面になる） | US1 |
| `/operator` | 要ログイン、かつ運営者 | 運営者向けの画面の入口（000 では空の案内。中身は `005`）。運営者でなければ 404 を返す | FR-025 |

- すべての画面の下部に、Cookie の同意のバナーを、未選択の間だけ表示する（FR-021）。選択は `/legal/cookies` で変えられる。
- エラーの表示は、アカウントの存在が分からない文言にする（FR-007、FR-009、FR-014）。
