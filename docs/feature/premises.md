状態は **確定 / 対象外 / 未決** のいずれか。

| ID | 項目 | 状態 | 内容（要約） | 出典 |
|---|---|---|---|---|
| P1 | 目的と中核価値 | 確定 | 個人・中小企業の名付け担当が、名前の候補について商標・Google 検索・ドメイン・SNS の使用状況を 1 回の入力でまとめて確かめ、候補を比べて絞り込める。商標検索と Web 検索を別々に手作業で行う手間を置き換える | core-concept.md、Q1、Q2、Q3 |

| P3 | 主要業務フロー | 確定 | 利用者: 候補を複数入力 → 区分（任意）と TLD を選ぶ → 一括実行 → 候補ごとに終わったものから比較表に表示 → 見比べて絞り込む → 後日、履歴から見返す・削除する。商標は同一と称呼類似を区分で絞り込んで示す。Google 検索は上位結果と一致の目安を示す | Q3、Q6、Q9、Q10、Q14、Q15 |
| P4 | 主要なドメインデータ | 確定 | 利用者 1—n チェック 1—n 候補。候補 1—1 商標照合結果、1—1 Web 検索結果、1—n ドメイン確認結果（TLD ごと）、1—n SNS 確認結果（SNS ごと）。利用者 1—n 利用回数（期間ごと） | Q3、Q4、Q16（分割案の合意で確認） |
| P5 | 外部サービス・連携 | 確定 | 日本の商標データ（取得手段は architecture で決める。J-PlatPat の自動取得は禁止）、Google 検索の結果（公式 API は 2027-01-01 に終了するため第三者 API などを architecture で選ぶ）、ドメインの空き確認、YouTube のハンドルの確認（公式 API）。X・Instagram・TikTok は手動確認のリンクだけを示す。決済は MVP では使わない | Q2、Q5、Q8、Q13、Q14、Q17、Q18、competitor.md §1.4 |
| P6 | 固有のセキュリティ・法規制 | 確定 | 扱う個人情報はアカウント情報のみ。候補名は未公開の商品名など機密情報になりうるため、本人のみ閲覧・削除でき、運営者も個別の候補名を閲覧しない。外部への送信は検索に必要な範囲に限る。結果は簡易チェックであり、類否の法的判断ではないと明示する。外部サービスの利用規約（J-PlatPat・各 SNS）に反する取得をしない | Q11、Q12、competitor.md §1.4 |
| P7 | 固有のリソース要件 | 確定 | 一括チェックは候補ごとに外部へ問い合わせるため時間がかかる。画面を閉じても処理を続け、候補ごとに終わったものから表示する（非同期処理が必要）。ファイル添付・オフラインは不要 | Q10 |
| P8 | MVP の範囲 | 確定 | 複数候補の一括チェック（商標・Google 検索・ドメイン・SNS）、比較表、履歴の保存・再表示・削除、ユーザーごとの利用回数の上限 | Q7、Q16 |
| P9 | 課金・プランの境界 | 確定 | MVP は無料で公開し、ユーザーごとに期間あたりの候補数の上限を設ける。有料プランと決済は後で入れる（backlog BL-001） | Q8、Q16 |
| P10 | 差別化とやらないこと | 確定 | 勝ち筋: 商標と Google 検索（＋ドメイン・SNS）を 1 回の入力で、複数候補を並べて比べられること。やらないこと: 商標出願の代行・連携、類否の最終判断 | Q2、Q3、Q12、competitor.md §1.3 |
